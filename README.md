Schriftart für Instagram und Co.

Die Seite nutzt nur eine Schriftfamilie: Archivo (kostenlos, Open-Font-Lizenz, bei Google Fonts erhältlich). Sie ist eine variable Schrift mit einstellbarer Breite. Die drei Stile, die du übernehmen willst:

Überschriften (OZEE, Release-Titel, „ALL RELEASES“): Archivo Expanded, ExtraBold (800), nur Großbuchstaben
Kleine Labels, Jahre, Menü (z. B. „LATEST RELEASE“): Archivo SemiCondensed, SemiBold (600), Großbuchstaben, weiter Buchstabenabstand
Fließtext: Archivo Regular (400), normale Breite
